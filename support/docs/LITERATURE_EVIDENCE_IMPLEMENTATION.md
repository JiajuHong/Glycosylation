# 第二层：透明文献证据检索

第二层只检索成功文献先例，不估计反应成功概率，不定义模型适用域，也不输出
人为加权的“兼容性总分”。候选条件本身来自真实完整条件模板；本层回答的是使用
该条件时，是否存在相同或相似供体—受体的成功记录。供受体组合的历史与
当前条件的证据分开记录，前者不参与条件排序。

## 供受体组合历史

`Pair_History` 只取 `known_pair` 或 `novel_pair`，表示该供体—受体组合
是否在任意条件下有成功历史。它是背景信息，不能证明当前候选条件合适。

## 当前条件迁移证据

`Condition_Transfer_Evidence` 按以下层级分类：

1. `exact_pair_exact_condition`：相同供体、受体和条件已有成功记录；
2. `same_donor_condition`：相同供体曾在该条件下成功；
2. `same_acceptor_condition`：相同受体曾在该条件下成功；
3. `analog_condition`：该条件有成功记录，但只找到其他底物；
4. `template_only`：参考库中没有完全相同条件的成功记录。

`same_donor_condition` 与 `same_acceptor_condition` 的排序等级相同，不预设
供体证据或受体证据更重要。

若同一条件分别存在相同供体和相同受体的记录，但没有完全相同的供受体对，
类型记为 `same_donor_condition`，两项计数仍分别保留。

## 原始证据字段

输出当前条件下的直接先例、相同供体和相同受体反应计数，以及供受体组合的全局
成功历史计数。结构相似度使用启用手性的
Morgan radius 2、2048 bit 指纹和 Tanimoto。联合相似度定义为：

```text
min(Donor_Tanimoto, Acceptor_Tanimoto)
```

取较小值是为了避免陌生供体被相似受体补偿，或反之。相似度只在完全相同
条件的成功反应中计算；`template_only` 不用其他条件下的相似底物补值。

## 推荐规则

Alpha/Beta 任务首先按三个冻结种子的目标构型投票分级：3/3 为“优先”，2/3 为
“探索”，最多 1/3 为“不推荐”。当前条件迁移证据只在同一投票等级内排序；
`Pair_History` 不参与排序。第三类任务始终是“探索性救援”，不能解释为反应成功预测。
